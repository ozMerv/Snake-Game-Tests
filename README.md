# Snake Game Tests

Snake Game Tests is a simple comparison project for testing AI coding models and agents using the same programming challenge.

The aim is straightforward:

**Each model must create a complete, playable Snake game contained entirely within a single HTML file named `classic_snake.html`.**

## Standard Test Prompt

> Create a complete, playable Classic Snake Game in a single HTML file named `classic_snake.html`.
>
> Use HTML, CSS and JavaScript only.
>
> Everything required to run the game must be contained within that one HTML file.
>
> The game must work when `classic_snake.html` is opened directly in a web browser.
>
> Do not use external libraries, frameworks, images, assets or additional files.

## Testing Principle

Every model receives the same prompt.

The generated `classic_snake.html` file is then saved and tested with minimal intervention.

The comparison focuses on:

* Whether the game works
* Whether it is genuinely self-contained
* How well the model interprets the simple prompt
* Gameplay quality
* Visual design
* Controls and usability
* Code quality
* Creativity and polish

## Rules

1. The same starting prompt is used for every model.
2. The completed file must be named `classic_snake.html`.
3. The result must be a single HTML file.
4. No external dependencies are permitted.
5. The HTML file must run directly in a browser.
6. Models are not shown other models' solutions.
7. Any follow-up prompts or manual fixes are recorded.

## Purpose

This is not intended to be a formal benchmark.

It is a simple, interesting way to compare what different AI coding models produce when given exactly the same small and clearly defined task.

The simplicity of the prompt is intentional. The differences between the resulting games are part of the fun.
